# Brain v3 — инфраструктура нового корпуса

Дата: 2026-09-15.

## Результат

Создан локальный шлюз качества для будущего русскоязычного корпуса Brain v3.
Он готов принимать только источники с явно записанным происхождением, лицензией,
контрольной суммой и разделением на train, validation и test.

Первоначальный пустой статус, описанный ниже, был корректен на момент создания
инфраструктуры. Позднее добавлен и отдельно проверен первый малый CC0-пилот
Tatoeba; актуальный результат приведён в `BRAIN_V3_TATOEBA_CC0_PILOT_REPORT.md`.
Даже с этим пилотом обучение остаётся правильно заблокированным.

## Созданные части

- `data/brain_v3/brain_v3_corpus_record.schema.json` — справочная JSON Schema
  двух типов записей: многоходовый `dialogue` и связный `language_document`.
- `data/brain_v3/corpus_manifest.v1.json` — единственный реестр разрешённых
  источников. На момент первоначального отчёта он был пуст; текущий малый
  проверенный источник всё ещё не проходит полную quality gate.
- `data/brain_v3/CORPUS_DATA_CARD.md` — правила источников, лицензий,
  приватности, split и условия допуска к обучению.
- `ai_core/brain_v3_corpus.py` — строгий потоковый аудитор, который проверяет
  SHA-256 источника и записи, provenance, язык, чередование ролей, URL, PII,
  похожие на секреты данные, инъекции, точные дубли и кандидаты на близкие
  дубли.
- `evaluation/audit_brain_v3_corpus.py` — воспроизводимый запуск аудита с
  отдельным Markdown и JSON-результатом.

Тексты записей не попадают в результат аудита: он сохраняет только счётчики и
коды причин. Сырые JSONL предназначены для `data/brain_v3/raw/` и не
переписываются этим процессом; будущий очищенный набор будет отдельной версией
в `clean/` только после успешного аудита.

## Проверенный начальный статус

Запуск на пустом реестре сохранён в
`evaluation/results/brain-v3-corpus-empty-audit-v0.1/`:

- источников: `0`;
- принятых и отклонённых записей: `0`;
- `training_allowed`: `false`;
- причины: нет разрешённых источников, записей, всех split, достаточного числа
  диалоговых ходов и языковых символов.

Это ожидаемый результат. Он доказывает, что новая инфраструктура не подменяет
настоящий корпус старым Chat AI Dataset, тестовыми сценариями или данными чата.

## Минимальная quality gate

Для первой попытки генеративного обучения манифест требует:

- не менее `20 000` уникальных диалоговых ходов;
- не менее `100 000 000` символов лицензированных языковых документов;
- все три независимых split;
- нулевую долю строк, отклонённых безопасным аудитом.

Эти пороги можно изменить только явным решением с записью причины. Само наличие
папки, большого ZIP или похожих фраз не считается качественным корпусом.

## Проверки

`7/7` изолированных тестов успешно проверили:

- чистый маленький fixture проходит свою отдельную тестовую gate;
- URL, изменённый content hash и нарушение provenance блокируют материал;
- кандидат близкого дубля между train и validation не попадает в корпус;
- относительный путь не может выйти за папку `data/brain_v3/`;
- очищенный output не может быть выдан за неизменяемый raw-источник;
- пустой реестр остаётся заблокированным.

Итоговая регрессия всего проекта также прошла: `132/132` тестов за `94.913`
секунды. Рабочие маршруты чата, погоды, памяти и интернета не были изменены.

Ни внешний материал, ни пользовательские чаты не скачивались, не копировались
и не использовались для обучения. GitHub не изменялся.

## Следующий шаг

После решения пользователя о разрешённых источниках добавить первый маленький
лицензированно чистый источник в `raw/`, проверить его SHA-256 и лицензию,
внести запись в manifest и прогнать аудит. Только затем можно создавать
версионированный cleaned-корпус; до выполнения полной quality gate генератор
обучаться не будет.
