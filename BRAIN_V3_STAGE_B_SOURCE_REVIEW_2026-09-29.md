# Brain v3 — source review этапа B, 29 сентября 2026 года

Статус: review-only; ничего не скачано и не добавлено в corpus.

## Зачем проводилась проверка

После закрытия expanded acceptance contract проверены только первичные
страницы потенциальных русскоязычных разговорных источников. Цель — найти
candidate с ясным происхождением и правами, а не формально увеличить corpus.

## Результаты

| Кандидат | Решение | Обоснование |
| --- | --- | --- |
| RUMBA | Только будущая evaluation-возможность | Официальный проект называет себя Russian User Memory Benchmark; он предназначен для оценки долговременной памяти и использует многосессионный формат. Его не смешивают с training corpus. |
| RLDD / `inkoziev/Conversations` | Отклонён | Карточка показывает `CC-BY-4.0`, но README устанавливает `CC-BY-NC-4.0`; кроме того, заявлены форумы, литература, шутки и синтетическая часть. Это конфликт лицензии и неединое происхождение. |
| UltraLink | Отклонён | Репозиторий описывает data-augmentation и зависимость от других chat/source datasets, включая ShareGPT; MIT относится к repository/model release и не доказывает разрешение на весь исходный текст для проекта. |
| Dialogs (2026) | Отклонён для text-brain | Это studio conversational speech corpus, заявленный для TTS, с OpenRAIL-лицензией. Он может быть отдельной темой для будущей voice-оценки, но не является разрешённым русским text dialogue source текущего этапа. |

## Вывод

Ни один новый источник не проходит одновременно требования original
provenance, разрешённой licence, русскоязычного text dialogue назначения и
нетемплейтного качества. Поэтому data gate не ослабляется, ничего не
скачивается, active manifest не меняется и `generator_training_ready` остаётся
`false`.

Следующий безопасный путь — создать ограниченный project-owned original
candidate строго по `DIALOGUE_AUTHORING_PROTOCOL.md`, вручную проверить его и
только затем запускать уже существующие staging/audit/coverage инструменты.
