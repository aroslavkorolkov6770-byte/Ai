# Brain v3 — Russian Everyday Dialogues: диалоговый пилот

Дата: 16 сентября 2026 года.

## Назначение

Этот шаг добавляет первый маленький лицензированно чистый материал типа
`dialogue` в Brain v3. Он проверяет весь путь приёма многоходовых данных и не
является заявлением о готовом «человеческом» интеллекте или разрешением на
обучение генератора.

## Источник и закрепление версии

- Карточка источника: <https://huggingface.co/datasets/kukunechka/russian-everyday-dialogues>.
- Авторская карточка описывает 20 самописных русских бытовых диалогов и
  `CC-BY-4.0` с обязательной атрибуцией.
- Использован только pinned revision
  `3d9c43ca85a50e7a32fa7b05e27c0637a710e988`, а не mutable ветка `main`.
- SHA-256 исходного JSONL:
  `2599fe92d9f976e262f89b50dc5ec02b97bd2c3f2edad965b83d74e38ecd4169`.
- Атрибуция: Ekaterina Myskina (2025), Russian Everyday Dialogues, Hugging
  Face.

Сборщик `ai_core/russian_everyday_dialogues.py` не использует
`datasets.load_dataset`, не запускает remote code и не принимает произвольный
URL. Он допускает только закреплённый HTTPS path, exact SHA-256, 20 строк
ожидаемой схемы и ограниченный размер ответа; редиректы, изменение revision,
пустые строки, лишние поля и несовпадение coverage блокируют запись.

## Смысловая очистка

Бытовой диалог может содержать локальную цену, маршрут, расписание, срок
возврата или другое изменяемое утверждение. Такие фразы не следует переносить
в будущую общую модель как факт. Поэтому до конвертации источник фильтруется по
объявленным тегам и bounded local-fact markers.

- Прочитано строк: `20`.
- Исключено контекстно-зависимых local facts: `9`.
- Создано Brain v3 dialogue-записей: `11`.
- Диалоговых ходов: `22`.
- SHA-256 staging JSONL:
  `21924f77a5de33f6023a659d6149d11db03d83336f6c0edf3a184aeffff89773`.
- Split после фильтрации: train `8`, validation `1`, test `2`.

Тексты диалогов и теги не дублируются в отчётах. Внутри каждой записи есть
строгая схема ролей `user → assistant`, provenance и content SHA-256.

## Честное ограничение и следующий шаг

Quality gate остаётся закрытым: `22` из нужных `20 000` диалоговых ходов и
`5 176 552` из нужных `100 000 000` языковых символов недостаточно для
decoder-only Transformer. Этот пилот доказывает качество процедуры, а не
масштаб будущей модели.

Следующий приоритет — несколько крупных источников с недвусмысленной
CC0/CC-BY-лицензией и ясным происхождением, либо собственный корпус, созданный
с явным согласием и ручной проверкой. Крупный RLDD-кандидат не импортирован из-
за противоречия между metadata `CC-BY-4.0` и README `CC-BY-NC-4.0`, а также
разнородного происхождения.
