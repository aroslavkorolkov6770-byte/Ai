## Исправление PDF

В тестовом сайте добавлен `app/components/PdfDocumentViewer.tsx` и его CSS-модуль.
PDF отображается через локальный PDF.js 5.4.296 на canvas, без зависимости от
встроенного PDF-плагина браузера. Использована уже установленная версия библиотеки;
она явно закреплена в package.json/package-lock.json. Обработчик, шрифты и ресурсы
копируются из node_modules в public/pdfjs/5.4.296. Внешний CDN не используется.
Основа способа отображения: [официальный пример PDF.js](https://mozilla.github.io/pdf.js/examples/).

Также исправлен пропуск автоматического открытия: отметка о выполненном переходе
раньше устанавливалась до таймера, который мог отменить повторный эффект React.
Теперь отметка ставится при фактическом запуске. Поздний ответ загрузки не открывает
уже закрытое окно и не подменяет документ, выбранный пользователем после него.

Возможности: перелистывание, масштаб по ширине/150%/200%, ограничение canvas
8 миллионами пикселей, отмена незавершённой отрисовки, освобождение обработчика при
закрытии, понятные сообщения для повреждённого и защищённого PDF. Отдельная вкладка
использует тот же адрес документа с повторной проверкой доступа на сервере.
Права получения исходных байтов через /api/storage сохранены.

## Повторный запуск

Из корня Ai в текущем PowerShell:

```powershell
$env:VATES_TEST_POWERSHELL = (Get-Process -Id $PID).Path
node evaluation/closed_search/soak_http.cjs 900 8016
```

Оболочка выбирается из уже запущенного процесса; ExecutionPolicy не меняется.
Порт должен быть свободен. Runner создаёт отдельную конфигурацию, случайный секрет
только в памяти, базу и сервер; после завершения останавливает только созданное
им дерево процессов. В отчёт ключ не записывается. Рабочий поиск 8001 не останавливается.

Для запуска сайта launcher `scripts/start_closed_search_lab.ps1` теперь подготавливает
ресурсы PDF перед новым процессом Next. Прямые `npm run dev` и `npm run build` тоже
выполняют `prepare:pdf`. После обновления PDF.js версия библиотеки и обработчика
должны меняться вместе. Изменения сделаны только в копии тестового сайта.
