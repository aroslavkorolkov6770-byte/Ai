## Решение об использовании

Набор подходит для узкой локальной сети, которая выбирает действие вокруг веб-поиска. В ней используются только:

- реплики с ролью `user`;
- метка `browse_label`.

Не используются и не исполняются `system`, `assistant`, `tool`, `ideal_response`,
`evidence`, `search_queries`, `decision_rationale` и приложенный
`validate_package.py`. Поэтому набор не добавляет в ИИ готовые ответы, ссылки
или инструкции из архива.

Набор **не** подходит для свободной генерации: 200 синтетических seed-примеров
недостаточно, чтобы надёжно научить самодельную языковую модель вести любой
диалог. Для этого понадобятся отдельные согласованные данные и независимая
приёмка качества ответа.
