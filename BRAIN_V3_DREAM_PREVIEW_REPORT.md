# Brain v3 — DReaM-ru-open: ограниченный предварительный снимок

Дата: 16 сентября 2026 года.

## Зачем выполнен этот шаг

Перед полным приёмом нового источника нужно было проверить, что официальный
Korp API можно читать воспроизводимо, не затрагивая restricted-части DReaM и не
создавая тысячи копий одного предложения. Этот шаг проверяет только техническую
границу источника. Он не является полным импортом и не даёт разрешения на
обучение.

## Источник и границы

- Официальная карточка: <https://spraakbanken.gu.se/en/resources/dream-ru-open>.
- Лицензия, указанная владельцем: `CC-BY-4.0`.
- Единственный разрешённый Korp corpus id: `DREAM-RU-OPEN`.
- Единственный разрешённый endpoint: `https://ws.spraakbanken.gu.se/ws/korp/v8/query`.
- Модуль `ai_core/korp_dream_ru_open.py` не принимает произвольный URL, corpus
  id или папку назначения из CLI. HTTPS, host, путь endpoint, параметры, JSON,
  размер ответа, таймаут, повтор запроса и запрет редиректов проверяются в коде.
- Любой результат пишется только в `data/brain_v3/staging/`; автоматического
  переноса в `raw/`, изменения `corpus_manifest.v1.json` или запуска обучения нет.

## Результат preview v0.1

Один ограниченный запрос с page `0..19` получил `20` KWIC-совпадений. После
нормализованной дедупликации осталось `2` уникальных русскоязычных кандидата;
`18` совпадений были точными повторами контекста. Это подтверждает исходную
проблему: Korp возвращает контекст по совпавшим токенам, поэтому постраничный
обход без дедупликации нельзя использовать как импорт предложений.

- API сообщил: `1 020 355` hits.
- Записано: `2` staging-записи; отклонено: `18` повторов.
- Снимок: `data/brain_v3/staging/dream-ru-open-preview-v0.1.jsonl`.
- SHA-256 снимка: `b48ce2dfc4d77d846f49b71d6a244ebeb5942c8d7beab773027c2d19836f3b7f`.
- Машинный отчёт: `evaluation/results/dream-ru-open-preview-v0.1/dream_ru_open_preview.json`.

Текст самих предложений не включён в этот отчёт.

## Проверка после изменения

- `6/6` новых изолированных тестов адаптера прошли: allowlist endpoint,
  запрет restricted corpus, staging-only запись, дедупликация, запрет
  перезаписи и ограниченная повторная попытка сети.
- Полная регрессия проекта: `151/151` тестов, `97.943` секунды, `OK`.
- Повторный audit активного корпуса по-прежнему принял `22 789` записей без
  отклонений, но `training_allowed=false`: `0` уникальных диалоговых ходов и
  `1 218 328` языковых символов ещё не проходят quality gate.

## Статус preview и последующее решение

Этот v0.1 остаётся историческим техническим снимком: он показал, почему
наивный token-query нельзя считать импортом предложений. После него был создан
sentence-anchored сборщик, выполнен полный v0.2, выявлены три cross-source
пересечения с Tatoeba и создан очищенный v0.3.

v0.3 прошёл независимый staging audit и preflight без отклонений, после чего
был добавлен локально в active manifest как `dream-ru-open-cc-by-v1`. Полный
учёт, контрольные суммы, split-метрики и итоговый quality gate находятся в
`BRAIN_V3_DREAM_COLLECTION_REPORT.md`. Обучение по-прежнему не запущено:
языковой источник не заменяет требуемые `20 000` уникальных диалоговых ходов.
