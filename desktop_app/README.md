# Ватэс AI — настольное приложение

Открывайте ярлык **Ватэс AI** на рабочем столе. Само приложение находится в `dist/VatesAI-win32-x64/VatesAI.exe`.

## Как пользоваться

1. Откройте «Локальный API».
2. Нажмите **Включить API**. Дождитесь состояния «Включён» и сообщения о готовности нейросети. При первом старте загрузка может занять больше времени; предел ожидания — пять минут.
3. Общайтесь в разделе «Чат с Ватэс» или используйте адрес API в другой программе на этом ноутбуке. По умолчанию это `http://127.0.0.1:8000`; HTTP-маршруты существующего API не изменены.
4. Нажмите **Выключить API**, чтобы освободить память и порт. Его можно включить снова.

Сворачивание оставляет API работающим. Закрытие окна выключает API, который запустило приложение. Повторное открытие ярлыка поднимает уже открытое окно. Если приложение аварийно завершится, сервер отслеживает закрытие его канала управления и прекращает работу; предусмотрен запасной предел завершения в 15 секунд.

Если порт занят, программа не завершает чужой процесс. Выберите свободный порт в этом же разделе. Выбранное значение сохраняется. Если сервер был запущен старым скриптом `start_chat`, останавливать его следует в том окне; настольное приложение не присваивает себе чужие процессы.

## Что действительно работает

- Собственное окно Windows, ярлык и SVG-иконки интерфейса.
- Запуск существующего Python API без терминала; остановка только своего процесса.
- Проверка `/health` с проверкой идентификатора именно запущенного экземпляра.
- Реальный чат через `/generate`, локальная история и экспорт Markdown.
- Сведения о реально загруженных компонентах, журнал, изменение порта и выбор папки проекта.
- Обзор 50 продуктов, поиск, избранное, светлая и тёмная темы.

Раздел «Мои материалы» скрыт: отвечать по произвольным документам эта версия пока не умеет. Обучение представлено планом. Фиктивные обучение, оценки качества и применение весов не доступны в рабочем приложении. Исходный интерактивный прототип сохранён отдельно в `../desktop_preview/index.html`.

## Где находятся файлы

Код интерфейса и управляющего процесса упакован в `resources/app.asar`. Windows-среда Electron включена в папку приложения, Node.js для обычного запуска не нужен. Python-обёртка находится в `resources/backend_runner.py`.

**Это локальная установка для данного ноутбука, а не переносимый единый EXE со всеми весами.** Приложение использует текущую папку `C:\Users\KROLL\Desktop\AI`, её `.venv`, `ai_core`, `model_artifacts` и данные. Их нельзя удалять после создания ярлыка. Существующие модель и данные не копируются и не заменяются упаковкой. Если папка перенесена, укажите её в «Настройках» при выключенном API.

Настройки интерфейса, история, конфигурация и журналы находятся в пользовательской папке приложения `%APPDATA%\Vates AI`. Точное расположение журнала открывается кнопкой «Открыть папку». Активный журнал ограничен примерно 2 МБ; сохраняется одна предыдущая копия.

Сервер отдельно сохраняет настоящие диалоги в своей SQLite-базе в `conversation_data`. Отключение истории интерфейса не удаляет серверную историю. В режиме `auto` существующая нейросеть может обращаться к интернету для актуальных вопросов; настольная оболочка не меняет это поведение.

## Сборка и проверка для разработчика

Исходники находятся в этой папке; `package-lock.json` фиксирует зависимости. Выполните `npm ci`, затем `npm run build:ui`. Для упаковки нужен официальный архив Electron версии, указанной в package.json, в папке `vendor`. Его SHA-256 проверяется по `node_modules/electron/checksums.json`. Иконка создаётся скриптом `build-icon.ps1`, сборка — `npm run package`, ярлык — `create-shortcut.ps1`.

Существующая папка результата не перезаписывается автоматически. Следующую сборку нужно выпускать в новую папку, после проверки менять целевой путь ярлыка. Не удаляйте приложение или его ресурсы во время работы.

`npm test` проверяет конфликт порта, отмену запуска, отсутствие файлов, настоящий ответ нейросети, повторные запуски/остановки и аварийное завершение родителя. Тестовая переписка использует отдельную временную SQLite-базу, а не пользовательскую историю. Обучение не запускается.

При реализации использованы рекомендации [Electron по изоляции интерфейса](https://www.electronjs.org/docs/latest/tutorial/security): sandbox, context isolation, ограниченный IPC-мост и собственный протокол ресурсов. Это базовая защита; углублённый аудит безопасности не проводился.
