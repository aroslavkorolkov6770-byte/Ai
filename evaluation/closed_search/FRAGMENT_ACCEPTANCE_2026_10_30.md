# Приёмка адресных ссылок — 30.10.2026

План зафиксирован до изменения алгоритма. Работа только в Desktop/Ai и его
изолированном стенде 3040, API 8001. Оригиналы Downloads не изменяются.

1. Сравнение Дао/Феникс выдаёт две разные ссылки, хотя файл общий; каждая открывает свою позицию.
2. Ссылка на обычный документ открывает соответствующий раздел/фрагмент, не соседний.
3. Две части с одинаковым заголовком различаются по содержимому.
4. Ссылка работает после перезапуска индекса и не запускает OCR.
5. Профиль Б читает доступную карточку; профиль А и анонимный запрос не получают её текст и название.
6. Отзыв доступа блокирует старую ссылку сразу, даже до обновления поискового индекса.
7. Новая редакция блокирует старую ссылку; старый текст не показывается как новый.
8. Новый ответ после индексации ведёт к новой редакции; соседние материалы не меняются.
9. Удаление/архивирование материала блокирует ссылку.
10. Неизвестный фрагмент не заменяется случайным разделом; изменение параметра не обходит доступ.
11. Урок и ссылка между документами сохраняют связь с настоящим источником цитаты.
12. Ответы и память сравнения товаров сохраняют прежнее поведение.

Проверки: локальные тесты поиска, HTTP с двумя настоящими тестовыми сессиями,
визуальное открытие ссылок в браузере. Мутации редакций/прав выполняются только
на новых явно учебных документах с восстановлением исходного состояния.
Следующий шаг после приёмки: реальные актуальные документы и сканы, сложные
ссылки на несколько разделов и точное положение на странице PDF.
