# Таблицы без рамок и связи страниц — 29.10.2026

Семь оригинальных PDF / одиннадцать страниц. Все правила вымышлены; файлы
содержат только растр. Это проверочные материалы, а не правила компании
и не корпус для обучения весов. `spec.json` зафиксирован до изменения OCR:
11 основных вопросов и 3 отложенные формулировки.

Проверяются три колонки без рамок, пустая ячейка, перспективное изображение
листа, перенос незаконченной строки между двумя страницами, правильный и чужой
номер таблицы в продолжении/сноске. Ожидания взяты из исходных правил,
результат OCR не используется как эталон. Генератор `layout_assets.py`
отказывается перезаписывать уже существующие PDF.

На изолированном сайте исправные документы доступны тестовым сотрудникам,
три намеренно повреждённых — только испытательному администратору. Поэтому
ошибочный вариант с тем же товаром не загрязняет обычный поиск сотрудника.
В локальном наборе каждый вопрос явно выбирает свой файл.

Генерация и рендер: bundled Python с Pillow, reportlab, numpy, pypdf и Poppler.
Проверка извлечения: проектная `.venv` с Tesseract rus+eng и OpenCV.
Команды из корня Desktop/Ai:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m evaluation.closed_search.layout_probe
.\.venv\Scripts\python.exe -X utf8 -m evaluation.closed_search.layout_probe --holdout
node evaluation/closed_search/layout_http.cjs
node evaluation/closed_search/layout_revisions.cjs
```

Фотография изготовлена проективным преобразованием чистого листа. Она не
заменяет отдельную приёмку снимков камерой, рукописи, бликов, смазанных цифр
и обрезанных краёв. Прямоугольные заголовки/строки без явных признаков
продолжения на другую страницу автоматически не склеиваются.
