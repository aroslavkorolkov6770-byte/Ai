# Контрольные сканы — 29.10.2026

Пять оригинальных вымышленных PDF, шесть страниц. Все исходные PDF содержат
только растр, без скрытого текстового слоя. `spec.json` задаёт 9 основных и
2 отложенных вопроса; ожидаемые факты зафиксированы до изменения извлечения.
Изготовление: `evaluation/closed_search/scan_assets.py` (bundled Python с Pillow,
reportlab и pypdf). Скрипт отказывается перезаписывать уже замороженные файлы.

Проверяются двухуровневые объединённые заголовки, общая ячейка для двух строк,
две страницы, небольшой наклон, сноска, смена значения/исключения и пустая ячейка.
Пустая ячейка в «Коралл» намеренна: в ней нет подтверждённого срока.

Тесты не используют OCR-результат как эталон. Эти документы не являются
правилами компании, пользовательским корпусом или данными обучения весов.
Сканы изготовлены программно; приёмка произвольных фотографий реальных бумаг
по этому набору не заявляется.
