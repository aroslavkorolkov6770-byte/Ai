# Качество сканов — замороженный набор 29.10.2026

11 оригинальных растровых PDF / 11 страниц, без текстового слоя. Все правила
вымышлены. В spec.json сохранены SHA256 каждого PDF, 11 основных вопросов
и 3 отложенные формулировки. Генератор quality_assets.py запрещает перезапись
существующего набора. Ожидания зафиксированы до запуска исходного алгоритма.

Шесть читаемых вариантов должны давать ответ: чистая таблица, лёгкое размытие,
тень, JPEG-сжатие, чёткий запрет и тень на запрете. Три явно повреждённых
должны вызывать unavailable: сильное размытие, обрезанный столбец и потерянное
при обрезке начало строки с отрицанием. Для двух пограничных вариантов
(локальное размытие цифр и повреждённое «не») разрешены только точный ответ
или unavailable. Совпадение статуса само по себе не считается успехом:
проверяются содержание, числа, ссылка и отсутствие фактов в отказе.

На итоговом алгоритме шесть читаемых вариантов дали правильные ответы,
остальные пять — отказ. Отложенные формулировки проверены отдельно.

Файлы изготовлены программно: это не фотографии камерой. Приёмка рукописи,
бликов, произвольной обрезки или всех ошибок OCR этим набором не заявляется.
Намеренные визуальные повреждения — часть теста, не дефект генератора.
Все 11 страниц отрендерены Poppler и просмотрены на контактных листах.

На сайте пять отрицательных вариантов доступны только испытательному admin.
Числовые вопросы используют явный выбор PDF: в старом наборе стенда уже
есть отдельная HTML-таблица с вымышленным товаром Селенит. Новые ожидания
и PDF после обнаружения совпадения имени не переписывались.
