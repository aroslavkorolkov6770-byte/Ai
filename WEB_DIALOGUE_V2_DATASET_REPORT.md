# Расширенный набор веб-диалогов v2

## Назначение

`training_data/web_dialogue_examples_v2.jsonl` — дополнительный ручной набор из 40 многоходовых веб-примеров. Он расширяет темы HTML, CSS, JavaScript, DOM, Fetch, доступности, React и Vite. Набор подключается явно флагом `--include-extended-web-dialogue`, чтобы отклонённый эксперимент не менял обычный запуск обучения.

Каждая строка содержит начальную пару реплик и уточняющий вопрос с коротким ответом. Набор подключается только к train-части при обучении темы `web`; исходный `training_data/dataset.jsonl`, validation и test не изменяются.

## Проверки

- Примеров в новом файле: `40`.
- Всего веб-диалоговых примеров после объединения с прежним файлом: `71`.
- Всего диалоговых train-примеров v1.4: `76` — 20 из общего файла и 71 веб-пример.
- Точных пересечений с 12 сценариями `web_followup_eval.jsonl`: `0`.
- Все строки проходят загрузку JSONL и преобразование в формат `TrainingPair`.

## Результат первого обучения

Новый набор проверен в кандидате `tiny-gru-bpe-web-v1.4-dialogue-expanded`. При неизменных архитектуре и параметрах обучения validation loss снизился до `2.6953`, test loss — до `3.0050`, но внешнее качество ухудшилось: neural-only сходство на 28 веб-вопросах составило `0.2961` против `0.3092` у v1.3. На follow-up benchmark v1.4 получила `0.2117` с контекстом против `0.2261` у v1.3.

Кандидат отклонён. Его артефакты сохранены отдельно в `model_artifacts/versions/gru-bpe-web-v1.4-dialogue-expanded-candidate`, а рабочая v1.3 восстановлена из `model_artifacts/versions/gru-bpe-web-v1.3-before-dialogue-v1.4`.
