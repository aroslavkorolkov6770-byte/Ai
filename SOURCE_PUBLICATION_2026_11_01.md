## Проверка кода без обученных весов

Для Windows PowerShell из корня клонированного репозитория:

```powershell
py -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe -m unittest discover -s tests -p 'test_site*.py'
```

Полные проверки контроллера настольного приложения требуют Node.js, настроенного окружения .venv внутри проекта и необходимых локальных артефактов модели:

```powershell
node --test desktop_app/tests/controller.test.cjs
```

Тесты закрытого поиска используют собственные тестовые материалы. Для отдельных исторических экзаменов и обучения понадобятся исходные документы/данные, указанные в соответствующих сценариях. Для запуска OCR требуется локальный Tesseract с языками rus и eng, а также доступный pdftoppm; установка Python-зависимостей сама эти инструменты не устанавливает. Языки должны быть доступны Tesseract либо размещены файлами rus.traineddata и eng.traineddata в .runtime/closed-search/ocr-tessdata. В рабочей установке русский язык находится именно в этом локальном каталоге; сами языковые файлы в репозиторий не включены. Без локального окружения тесты запуска реального API настольного приложения не являются автономными.
