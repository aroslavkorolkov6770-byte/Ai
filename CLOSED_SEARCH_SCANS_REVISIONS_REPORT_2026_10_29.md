## Что теперь работает

Скан с видимой сеткой больше не превращается в одну длинную строку. Новый
`ai_core/site_scan_tables.py` исправляет небольшой наклон, выделяет горизонтальные
и вертикальные границы, восстанавливает прямоугольные объединённые ячейки и
привязывает слова Tesseract к ячейкам по координатам. Заголовки могут занимать
несколько строк/столбцов; общая ячейка предмета может относиться к нескольким строкам.
Значения наследуются только внутри физически объединённой ячейки, не из пустого
соседнего поля.

Из заголовка «Срок хранения / Если упаковка вскрыта» и строки «Аметрин / 2 дня»
получается проверяемое условное правило для Аметрина. Строка Турмалина с другим
сроком не примешивается. Условия по строкам объединяются только у того же предмета
и календарного периода. Столбцы начала/окончания действия превращаются в явный
период для уже существующего выбора по дате. Произвольное неявное условие не
объявляется понятным.

Сноски сохраняются вместе с определениями, включая перенос на следующую строку.
Их номера получают внутреннюю привязку к странице; одинаковые номера разных
страниц не склеиваются. Номер страницы/таблицы остаётся в сведениях об источнике.
Краткое содержание сохраняет условия; номера страниц больше не создают ложный
конфликт чисел.

Если граница частично разрушена, ячейка пуста, слово пересекает соседнюю ячейку
или уверенность OCR недостаточна, документ помечается как структурно неоднозначный.
Текст остаётся доступен для определения темы, но фактический ответ и резюме по
этому документу не выдаются. Числа и отрицания имеют отдельный порог уверенности.
Это эвристика контроля качества, не доказательство безошибочности OCR.

Разделены два состояния: `complete` означает, что обработаны все страницы;
`STRUCTURE_UNCERTAIN` — что структуру конкретного документа нельзя использовать
для ответа. Неоднозначный скан не меняет обычный ответ об отсутствии сведений
по постороннему вопросу на сообщение о неполной обработке всей базы.

## Фоновая обработка и актуальность

- PDF растрируется Poppler с разрешением 220 dpi. Tesseract `rus+eng` возвращает
  слова, координаты и уверенность. OpenCV `opencv-python-headless==4.13.0.92`
  установлен в проектную `.venv` и закреплён в `requirements.txt`.
- У скана может быть старый скрытый текстовый слой. Для страниц с крупным растровым
  изображением он не подменяет видимые данные: проверка искусственно добавленного
  невидимого текста «999 days» подтверждает чтение исходного изображения.
- Фоновое извлечение и результаты кэшируются. При вопросе OCR не вызывается.
- Версия `closed-documents-v4-scan-grid-<hash>` включает хеш кода извлечения:
  исправленный алгоритм не читает старый ошибочный кэш тех же байтов.
- Версия извлечения сохранена и в SQLite. После обновления OCR прежний плоский
  индекс не объявляется готовым; ядро ждёт новый снимок с исходными файлами.
- При смене редакции текущий манифест сайта сразу запрещает старый ответ.
  До готовности новой редакции возвращается состояние обработки. Старые условия
  и ссылки чата проверяются по текущей версии. После смены версии без повторного
  названия/уточнения короткий неоднозначный вопрос требует уточнения.

## Практические границы и следующий этап

Подтверждена работа линованных таблиц с прямоугольными объединениями заголовков
и вертикальными объединениями строк. Есть пределы: 20 столбцов, 80 строк,
500 элементарных ячеек, 12 таблиц на странице, 4 уровня заголовка. Проверен
небольшой наклон 0,4–0,65 градуса. Горизонтальное объединение значений в теле
таблицы, L-образная ячейка и частично разрушенная граница не угадываются.

Таблицы без рамок, сильная перспектива фотографии, рукопись, очень низкое
разрешение, продолжение одной строки между страницами и сноска на другой
странице пока не аттестованы. Для страниц без обнаруженной сетки остаётся
прежний общий OCR; этот путь не доказывает правильность табличных связей.
Текстовые PDF без крупного растрового изображения продолжают использовать
прежнее извлечение текста. Число успешных вопросов не означает понимание
любой будущей формы документа.

Следующий этап: независимые документы без рамок и фотографии с перспективой,
оценка ошибок чисел/отрицаний и безопасное распознавание неподдержанной таблицы;
затем перенос строк/сносок между страницами и проверка смены редакций такого набора.
В рабочую LMS изменения пока не интегрируются; публикации нет.
