# Brain v3 — политика добровольной оценки ответов

Дата: 15 сентября 2026 года.

## Зачем это нужно

Кнопки «Полезно» и «Нужна доработка» позволяют добровольно отметить качество
конкретного только что показанного ответа. Это сигнал для будущего ручного
анализа качества, а не механизм скрытого сбора переписок.

## Что сохраняется только после нажатия кнопки

В локальную SQLite-таблицу `response_feedback` попадают ровно три поля:

- случайный технический идентификатор ответа;
- выбранная оценка: `helpful` или `needs_improvement`;
- время сохранения оценки в UTC.

До нажатия кнопки в таблицу обратной связи ничего не записывается. Token для
проверки ответа подписан ключом текущего процесса и не содержит содержимого
диалога.

## Что обратная связь не копирует

Механизм оценки не записывает в `response_feedback`:

- текст вопроса пользователя;
- текст ответа ИИ;
- `conversation_id` и всю историю диалога;
- координаты, точность геолокации, название места или IP-адрес;
- URL, поисковую выдачу, модельный prompt и обучающие данные.

Обычная локальная память диалога продолжает работать по ранее существующим
правилам; обратная связь не расширяет её состав и не отправляет данные наружу.

## Границы использования

- Оценку можно сохранить только один раз для одного живого ответа.
- После перезапуска без специально настроенного локального
  `AI_FEEDBACK_SIGNING_KEY` старый token перестаёт действовать. Это намеренно:
  он не становится долгоживущим идентификатором пользователя.
- Оценка не запускает обучение автоматически.
- Для превращения обратной связи в учебный материал потребуется отдельное
  добровольное согласие на текст, ручное обезличивание, новый источник корпуса,
  аудит, quality gate и явное решение пользователя.
- Данные остаются локальными; на GitHub ничего не отправляется.
