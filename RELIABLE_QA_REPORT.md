# Отчёт о надёжном режиме одиночных ответов

Дата проверки: 2026-09-07

## Итог

Основным режимом API стал `reliable`: собственная сеть выбирает смысл вопроса, после чего декодер возвращает один целый проверенный ответ. Если уверенности недостаточно или тема не поддерживается, возвращается фиксированная просьба уточнить вопрос. Случайная последовательность букв в этом режиме конструктивно невозможна: выходной словарь сети состоит из идентификаторов смыслов, а не из отдельных букв или токенов ответа.

Свободная GRU+BPE-модель `tiny-gru-bpe-web-v1.3-dialogue` сохранена без изменений и доступна только через явный `response_mode=experimental`.

## Почему изменена архитектура

Диагностика старой свободной генерации показала около 31% точности следующего токена. Ошибка раннего токена меняла весь дальнейший текст, поэтому `sample` и beam search шириной 2, 3 и 5 не дали ни одного точного ответа на 28 отложенных веб-вопросах. Улучшение только декодера не могло устранить накопление ошибок.

Новая схема разделяет две задачи:

1. собственная двухслойная MLP-сеть определяет один из 32 изученных смыслов;
2. детерминированный декодер выдаёт связанный с этим смыслом полный ответ либо безопасное уточнение.

Готовые открытые веса, внешние языковые модели и чужие векторные представления не используются.

## Новая структура данных

- `training_data/qa_curriculum.json` содержит 32 смысла, полные ответы, отдельные train/validation-формулировки, негативные темы, смысловые опоры, контрастные группы и группы объектов.
- `evaluation/qa_acceptance.jsonl` содержит 80 отложенных случаев.
- `evaluation/qa_generalization.jsonl` содержит второй независимый набор из 48 случаев.
- 722 уникальные обучающие формулировки не пересекаются с обоими проверочными наборами.

Обе QA-приёмки прошли установленный порог. Отказ на известном вопросе не засчитывался как правильный ответ. Приоритет выбран консервативный: лучше попросить уточнение, чем уверенно выбрать неправильную инструкцию.

## Активный артефакт

- Модель: `web-qa-intent-v2.0`.
- Путь: `model_artifacts/reliable_qa/qa.pt`.
- SHA-256: `64A49953D0DF43CF20001B2BB8185AD5DB5EDB3019115DD787AC46F11483D45C`.
- Область: базовые вопросы HTML, CSS и JavaScript.

Это не универсальная языковая модель. Она не должна угадывать погоду, право, медицину или произвольные темы; для них корректным результатом является уточнение. Интернет-поиск остаётся отдельным явно включаемым инструментом и не расширяет знания весов автоматически.
