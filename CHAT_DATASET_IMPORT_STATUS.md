## Что принято в работу

Независимый `internet_router_100k.jsonl.gz` содержит `100 000` строк с
метками `USE_WEB`/`NO_WEB`, раздельные `train`/`validation`/`test`, без
повторяющихся id и без конфликтующих меток одинакового вопроса. На нём обучен
собственный локальный `internet-router-v1.0`.

Он получает только текст сообщения пользователя, расширяет автоматический
маршрут интернета для естественных вопросов и работает вместе с прежними
явными правилами. Порог `0.90` и минимум покрытия `0.05` не дают сомнительной
новой формулировке запускать медленный поиск. Внешние страницы и поля архива
не исполняются как инструкции.

Дополнительно из канонических chat split принят только безопасный слой policy:
уникальная реплика пользователя и её стабильная категория. На нём обучен
`conversation-brain-v1.0`, который отличает обычный диалог от прикладного
запроса. В него не передавались `assistant`, `system`, `context`, веб-контекст,
поисковый запрос или готовый ответ. Полный отчёт и ограничения находятся в
`CONVERSATION_BRAIN_TRAINING_REPORT.md`.

## Что намеренно не подключено к генерации

Основной диалоговый массив содержит повторяющиеся пары `context+user`, разные
assistant-цели для одинакового вопроса и пересечения формулировок между
split. Поэтому его нельзя безопасно обучать как свободный генератор: это
вернуло бы проблему случайных и противоречивых ответов.

Файл сохранён для будущего отдельного проекта: сначала потребуется новая
генеративная архитектура, очистка/дедупликация по сценариям и независимый
набор для проверки манеры диалога. Активный чат не был загрязнён этими
строками.
