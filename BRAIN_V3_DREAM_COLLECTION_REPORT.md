# Brain v3 — DReaM-ru-open: полный приём и локальная активация

Дата: 16 сентября 2026 года.

## Назначение

Этот отчёт фиксирует воспроизводимый приём открытого языкового источника для
будущей собственной русскоязычной модели. Он не описывает обучение модели и не
содержит предложений из источника.

## Происхождение и границы

- Официальная карточка: <https://spraakbanken.gu.se/en/resources/dream-ru-open>.
- По карточке источника: открытая русская часть DReaM, лицензия `CC-BY-4.0`.
- Доступ выполнялся только через официальный Korp API
  `https://ws.spraakbanken.gu.se/ws/korp/v8/query`.
- Единственный разрешённый corpus id: `DREAM-RU-OPEN`.
- Запрос фиксированного сборщика: CQP `<sentence> []+ </sentence>` с
  `show_struct=sentence_id`; это даёт один hit на структурное предложение, а не
  по одному hit на совпавший токен.
- Атрибуция в manifest и каждой записи: Språkbanken, DReaM-ru-open (2019), DOI
  <https://doi.org/10.23695/gzsh-rp33>.

Сборщик `ai_core/korp_dream_ru_open.py` не принимает произвольные URL, corpus
id или каталог назначения. Он разрешает только HTTPS, точный host/path,
JSON-ответ ограниченного размера, заданный лимит страниц, таймаут и серверный
cache token. Редиректы, restricted-корпусы, HTML/XML и текст источника как код
не принимаются.

## Независимые проверки и очистка v0.3

Независимый staging audit v0.2 не нашёл внутренних дефектов. Однако временный
preflight вместе с уже активным Tatoeba обнаружил три cross-source пересечения:
два точных и один близкий. Поэтому v0.2 не переносился в `raw/`.

Добавлен локальный очиститель
`evaluation/clean_staged_dream_against_active.py`. Он сначала повторно проверяет
active corpus, затем сравнивает только fingerprint и SimHash каждой строки,
создаёт новый файл в `staging/` атомарно и никогда не перезаписывает исходный
candidate. В отчёты не попадают тексты записей.

Результат v0.3:

## Решение о качестве

Новый источник активирован только как проверенный языковой материал. Обучение
decoder-only Transformer **не запущено**: quality gate по-прежнему возвращает
`training_allowed=false`, поскольку не достигнуты `20 000` уникальных
диалоговых ходов и `100 000 000` языковых символов. Следующий приоритет —
лицензированно чистый многоходовый диалоговый корпус; нельзя заменять его
старыми конфликтными архивами или текстами пользовательских чатов.
