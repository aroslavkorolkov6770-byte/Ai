# Brain v3 — repair: результат инструмента вместо обещания

Статус: runtime acceptance repair; не является training dataset  
Дата: 2026-09-29  
Связанный candidate: `brain-v3-semantic-gap-candidate-v1.2`

## Причина

Пользователь отклонил `brain-v3-semantic-gap-v1.2-011`. В сцене был задан
конкретный вопрос о времени заката, но ответы говорили лишь «проверю» и
«покажу после проверки». Это не полезный итоговый ответ.

Отклонённая сцена и её verdict остаются immutable. Этот документ не заменяет
её и не превращает новый текст в corpus.

## Контракт поведения

1. Распознать weather/time/web intent и вызвать соответствующий проверяемый
   route.
2. Не подставлять значение из статического диалога: время, прогноз и другой
   изменяющийся факт берутся из свежего ответа route.
3. Вернуть пользователю результат route в этой же финальной реплике. «Проверю»
   допустимо только как внутренний этап, но не как показанный финальный ответ.
4. Учитывать явно запрошенный формат. Для «напиши только время» выводится
   ровно значение времени; URL не добавляется без прямой просьбы.
5. Если route недоступен, честно сообщить о недоступности, а не выдумывать
   значение и не отправлять пользователя к случайным поисковым ссылкам.

## Проверяемый пример

Ниже не реальный прогноз, а offline fixture для regression-теста:

```text
Пользователь: Я буду в Калуге. Во сколько сегодня закат?
weather route: fresh sunset_time = 19:32
ВатэсAi: Сегодня в Калуге закат в 19:32.

Пользователь: И напиши только время.
weather route: fresh sunset_time = 19:32
ВатэсAi: 19:32
```

Число `19:32` существует только в тестовой fixture. Оно не записано в
обучающий corpus и не выдаётся как актуальный факт вне теста.

## Реализация и проверка

- `ai_core/internet_search.py` распознаёт контекстное место перед вопросом,
  компактный weather follow-up и запрос «только время».
- `ai_core/api_server.py` передаёт только последнюю weather-реплику текущего
  диалога как ephemeral hint; ни координаты, ни эта подсказка не сохраняются
  как обучающие данные.
- `tests/test_internet_search.py` проверяет live formatter на fixture.
- `tests/test_auto_internet.py` проверяет, что API отдаёт результат route, а
  не текст действия.
- Отдельная live-проверка geocoder показала, что форма `Калуге` не находится
  напрямую, а запасная форма `Калуга` корректно разрешается в координаты. Это
  проверяет реальный крайний случай, не добавляя погоду или координаты в corpus.
- End-to-end live smoke-check подтвердил, что запрос с «Напиши только время»
  возвращает один результат формата `HH:MM`; конкретное актуальное значение не
  сохранялось в логах и не добавлялось в corpus.

Команда проверки:

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_auto_internet tests.test_internet_search
```

Результат: `35` route-тестов и `43` combined targeted tests успешно. Active
corpus, weights, training, GitHub и публикация не менялись.

## Независимый acceptance-контракт r3

В `brain-v3-russian-acceptance-v0.2` добавлены четыре evaluation-only сценария
для weather/web. Для них обязательны `tool_result_returned` и
`no_action_promise`; валидатор запрещает ставить эти свойства не-инструментному
маршруту или требовать отсутствие обещания без возврата результата.

`evaluation/results/brain-v3-contract-v0.2-r3/` фиксирует: 212 сценариев,
56 с историей, 4 проверяемых tool-result case. Это quality gate для runtime,
не training data и не активный продуктовый corpus.
