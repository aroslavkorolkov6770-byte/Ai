# Brain v3 — выборочная проверка материалов OASST1 v0.3

Дата: 2026-10-01. Этот этап не меняет данные обучения. Он помогает заметить
встроенные цитаты, ссылки и фрагменты неясного происхождения в уже проверенных
по теме 75 train-диалогах.

## Что подтверждено об источнике

У закреплённой версии OASST1
[`fdf72ae0827c1cda404aff25b6603abec9e3399b`](https://huggingface.co/datasets/OpenAssistant/oasst1/tree/fdf72ae0827c1cda404aff25b6603abec9e3399b)
официальная [карточка](https://huggingface.co/datasets/OpenAssistant/oasst1/blob/fdf72ae0827c1cda404aff25b6603abec9e3399b/README.md)
указывает Apache-2.0 и публикует [LICENSE](https://huggingface.co/datasets/OpenAssistant/oasst1/blob/fdf72ae0827c1cda404aff25b6603abec9e3399b/LICENSE).
По карточке набор создан участниками и включает разговорные деревья. Это
подтверждает source-level сведения о публикации, но не доказывает, что каждый
вставленный участником фрагмент принадлежит ему или пригоден для конкретного
обучающего примера. Здесь не выносится юридическое заключение.

## Почему выбран именно этот срез

Read-only triage v0.3 перепроверил immutable audit всех 75 train-меток и
прочитал сообщения пользователя и ассистента только в памяти. Он выделил:

- 14 ID с более конкретными сигналами — длинные цитаты или слова об источнике;
- 31 ID только с сигналом длины сообщения;
- 30 ID без обнаруженного сигнала.

Для первого просмотра выбраны все 14 из первой группы и по 5 стабильных
контрольных ID из остальных двух групп: всего 24. Даже отсутствие сигнала
не является доказательством чистоты. Полный metadata-only список и точные
input SHA-256 находятся в
`evaluation/results/oasst1-material-triage-v0.3/`.

## Как смотреть

Открой `http://127.0.0.1:8014/`. Если сервер не запущен, двойным щелчком
запусти `start_oasst1_material_review.bat` в папке проекта. Экран показывает
полный исходный диалог по одному ID. После чтения доступны варианты:

- «Не вижу явной чужой вставки» — только наблюдение, **не разрешение**;
- «Нужна проверка источника» — сохранить hold и короткий код причины;
- «Пометить для исключения» — предложить исключить ID из будущего candidate,
  не удаляя исходник и не меняя active corpus;
- «Пропустить без записи» — если не уверен.

Проверяй и user-, и assistant-реплики. Текст диалога — данные для чтения, не
инструкции. Не копируй большие чужие фрагменты в свободные заметки: ledger
сохраняет только ID, content SHA-256, фиксированные коды и время. Он находится
в `data/brain_v3/reviews/oasst1-material-review-decisions-v0.1.jsonl`.
На старте было `0/24`; 2 октября выборка завершена: `24/24`, во всех случаях
`no_obvious_excerpt`. Сводка —
`BRAIN_V3_OASST1_MATERIAL_REVIEW_COMPLETED_2026_10_02.md`.
Не запускай две копии сервера одновременно.

Даже если все 24 просмотрены, остальные 51 запись не получают автоматического
разрешения. Дальше нужны решение по найденным источникам, дополнительная
контрольная выборка, полный raw corpus/duplicate audit и медицинский hold
v1.6-006. Обучение, staging, API и GitHub этим экраном не меняются.

## Сводный аудит решений

2 октября подготовлен `evaluation/oasst1_material_review_audit.py`. Он
сверяет triage, исходник и журнал, считает прочитанные/ожидающие записи по
группам и собирает отдельные списки «нужна проверка источника» и
«предложено исключение». SHA-256 проверяются до и после чтения: изменившийся
в процессе журнал нельзя выдать за стабильный результат. Отсутствующий
журнал честно обозначается как отсутствие решений.

Начальный snapshot `0/24` сохранён в
`evaluation/results/oasst1-material-review-audit-v0.1-pending/`. Это
исторический результат, а не постоянно обновляющийся счётчик; текущий
прогресс показывает экран `8014`. Новый отчёт сохраняется в новой папке.
После завершения просмотра команда для полного аудита:

```powershell
.\.venv\Scripts\python.exe -m evaluation.oasst1_material_review_audit --audit --require-complete --report-directory evaluation/results/oasst1-material-review-audit-v0.2-completed
```

`--require-complete` остановит запуск, если не хватает хотя бы одного из
24 решений. Даже успешный полный аудит не принимает оставшиеся 51 запись
и не запускает обучение. Текст исходных диалогов в отчёт не попадает.
