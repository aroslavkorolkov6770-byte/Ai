## Уже сделано

- Создан простой веб-интерфейс на Streamlit.

- Датасет содержит 1329 пар вопросов и ответов.

## Что ещё мешает считать это готовым продуктом

- Ответы neural-only всё ещё слабые: текущий checkpoint имеет `validation_loss=2.6686`, `test_loss=2.7151` и test-посимвольную точность `0.2654`.
- История сохраняется в SQLite и ограниченно передаётся модели: до 6 сообщений и 1600 символов. Полноценное многоходовое понимание пока не заявляется, потому что модель не обучалась на диалогах.
- Контролируемый интернет-поиск уже реализован, но модель пока не умеет пересказывать найденные страницы; внешний API для сайтов и аутентификация ещё не готовы.
- Источники и права на расширение датасета ещё не зафиксированы.
- Для production-режима нужно заменить разрешённый для прототипа CORS `*` на список доменов и добавить аутентификацию.

## Выполнено на первом этапе

- Датасет исправлен: теперь все 1329 строк читаются как JSONL.
- Добавлен `WordTokenizer` со служебными токенами `<pad>`, `<unk>`, `<bos>`, `<eos>`, `<sep>`.
- Модель переведена на причинную маску, чтобы при генерации она не видела будущие токены.
- Обучение теперь использует вопрос, разделитель и ответ; ошибка считается для части ответа.
- Пути вычисляются относительно корня проекта, а не текущей директории терминала.
- Добавлено сохранение словаря, весов и метрик.
- API получает один формат `/generate` и сохраняет сообщения в SQLite.
- Веб-клиент использует `/generate`, сохраняет идентификатор диалога и выводит текст безопасным способом.
- Виртуальное окружение создано, основные зависимости установлены.
- Первое обучение и ручная проверка API выполнены на CPU.
- Добавлена собственная символьная токенизация: словарь уменьшен до 162 токенов.
- Добавлен локальный точный baseline из датасета; API явно сообщает источник ответа.
- Добавлен режим `use_knowledge_base=false` для проверки только генеративной модели.
- Добавлен фиксированный набор из 20 evaluation-кейсов и скрипт запуска проверки.
- Добавлен поиск похожих вопросов с порогом сходства и отдельным источником ответа.
- Добавлена метрика повторяющихся 3-грамм и аудит датасета `DATASET_AUDIT.md`.
- Добавлена encoder-decoder архитектура `TinySeq2SeqTransformer` для раздельного чтения вопроса и построения ответа.
- API автоматически распознаёт seq2seq checkpoint и совместим со старым причинным checkpoint.
- Добавлены сценарии запуска API и индикатор соединения в веб-клиенте.
- Добавлен opt-in интернет-поиск через `ai_core/internet_search.py`, endpoint `/search` и флажок в HTML-чате.

## Результат оценки 20 вопросов

- `local-dataset-exact-match`: 20/20 точных ответов.
- `neural-model`: 20 запросов действительно прошли через модель, но ответы пока часто повторяют частые последовательности символов.
- Для похожих формулировок baseline дал 5/5 точных ответов; это результат локального поиска, а не генерации.
- Поэтому результат 20/20 нельзя считать точностью нейросети: это точность временного локального baseline.
