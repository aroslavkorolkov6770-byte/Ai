# Подтверждённые решения по Brain v3

Дата фиксации: 15 сентября 2026 года.

Этот документ записывает только явно подтверждённые пользователем границы
следующей стадии. Он не даёт автоматического разрешения на публикацию, обучение
на личных переписках или использование непроверенных материалов.

## Разрешённые открытые источники

Для русскоязычного корпуса разрешены открытые тексты с явно указанной лицензией
CC0 или CC-BY. Каждый источник до загрузки обязан пройти отдельную проверку
страницы происхождения, лицензии, контрольной суммы, структуры и аудита корпуса.
Материал без ясной лицензии не добавляется.

## Язык первой версии

Первый большой этап ориентирован только на русский язык. Это позволяет не
смешивать токенизацию, правила качества и оценку разных языков в одном раннем
кандидате.

## Аппаратная граница

Подходящая GPU будет предоставлена позднее. До этого разрешён только небольшой
CPU-прототип: инфраструктура, токенизатор, проверки и очень малые эксперименты.
Масштабное предобучение и обещания качества до появления GPU запрещены.

## Добровольная обратная связь

Разрешена локальная добровольная оценка конкретного ответа. Она не должна
автоматически копировать историю чата, координаты, запросы пользователя или
текст ответа в обучающий корпус. Оценка не запускает обучение сама по себе:
сначала потребуется отдельный отбор, обезличивание, проверка и явное решение
пользователя о каждом новом учебном источнике.

## Неизменные ограничения

- Не используются готовые веса открытых языковых моделей.
- До отдельного распоряжения ничего не публикуется и не отправляется на GitHub.
- Вся существенная работа и решения фиксируются в Markdown-файлах проекта.
- Текущий чат и его рабочие специальные маршруты не переобучаются на новом
  корпусе до прохождения всех quality gate.

## 2026-09-20 — расширение списка проверяемых лицензий для ускорения корпуса

Пользователь разрешил использовать любые полезные источники, чтобы собрать
достаточный материал и качественно обучить собственную модель. Это разрешение
трактуется ограниченно и безопасно: для каждого кандидата по-прежнему нужны
ясное происхождение, закреплённая версия, явная совместимая лицензия, локальная
проверка структуры, фильтрация рисков, provenance, staging audit и cross-source
preflight. Не принимаются личные переписки, материалы с неясными правами,
нелегально полученные данные, готовые веса или исполняемый код из источника.

Для первого ускоряющего многоходового источника разрешена лицензия `MIT`.
Она добавлена в `accepted_licenses` активного manifest, но сама по себе не
добавляет ни одного файла и не разрешает обучение: Russian MultiWOZ должен
отдельно пройти весь intake-путь.

## 2026-09-21 — Apache-2.0 для проверенного диалогового источника

В рамках того же явно разрешённого пользователем сбора полезных материалов
для качественного обучения проверен ещё один источник с ясным происхождением:
OpenAssistant OASST1. Для него лицензия Apache-2.0 добавлена в
accepted_licenses local manifest только после проверки official dataset card,
закреплённой revision, локального snapshot, структуры, фильтрации рисков,
provenance, staging audit и cross-source preflight.

Это решение не даёт общего разрешения на любые Apache-2.0 материалы и не
отменяет прежние требования. Оно не разрешает использовать готовые веса,
неясные датасеты, личные переписки или исполняемый код из архивов. Само
присутствие лицензии в policy не заменяет отдельный audit и не запускает
обучение автоматически.

## 2026-09-21 — текущий порядок до первого обучения

Пользователь подтвердил текущий порядок работы: после достаточного объёма
corpus сначала подготовить и проверить целевой семантически разнообразный
dialogue-candidate, а не запускать генеративное обучение на перекошенной
базе. Цель candidate — закрыть обычную беседу, поддержку, выбор, исправления,
неопределённость, web-grounding, приватность, стиль и безопасные границы.

Переход к первому обучению собственной decoder-only Transformer-модели
допускается только когда candidate прошёл provenance/license review,
staging audit, active preflight, честный coverage audit и выборочную quality-
проверку. Это решение не разрешает promotion, публикацию, GitHub-операции,
использование готовых весов или обучение на личных переписках без отдельного
решения.
